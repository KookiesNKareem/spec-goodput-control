## Blockers And Notes

- vLLM V1 checks with vLLM 0.22.1 did not run on this host: the installed torch
  wheel required CUDA 13.0 while the host driver reports CUDA 12.7. The smoke
  failed with `RuntimeError: The NVIDIA driver on your system is too old`.
- Mistral initially hit a Hugging Face cache quota while downloading. Removing
  the unused V1 environment freed enough space for the target and AWQ draft.
- vLLM 0.6.3 warns that Mistral should use `tokenizer_mode=mistral`, but that
  mode fails for `mistralai/Mistral-7B-Instruct-v0.2` in this vLLM release
  because it expects a newer Mistral tokenizer filename pattern. The Mistral
  sweep therefore uses the default tokenizer mode.
